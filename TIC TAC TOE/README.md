#  AI Tic Tac Toe

##  Overview
This project is an AI-powered Tic Tac Toe game developed during the CodSoft Artificial Intelligence Internship. The AI uses the Minimax algorithm to make optimal moves, making it difficult for the player to win.

## Features
- Human vs AI gameplay
- Intelligent AI using Minimax Algorithm
- Command-line interface
- Unbeatable AI strategy

## Technologies Used
- Python
- Minimax Algorithm
- VS Code

##  Concepts Used
- Artificial Intelligence
- Game Theory
- Minimax Algorithm
- Decision Making

## Learning Outcomes
- AI search algorithms
- Game development
- Recursive programming
- Algorithm optimization
