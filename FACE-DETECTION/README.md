# Face Detection System

## Overview
This project is a Face Detection System developed as part of the CodSoft Artificial Intelligence Internship. It detects human faces in real-time using OpenCV and Haar Cascade Classifier.

## Features
- Real-time face detection
- Webcam support
- Detects multiple faces simultaneously
- Draws bounding boxes around detected faces

## Technologies Used
- Python
- OpenCV
- Haar Cascade Classifier
- VS Code

## Output
The application opens the webcam and detects faces in real time by drawing rectangles around them.

## Concepts Used
- Computer Vision
- Object Detection
- Haar Cascade Classifier

- Real-time video processing
