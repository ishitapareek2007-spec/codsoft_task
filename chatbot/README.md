#  AI Chatbot

##  Overview
This project is an AI Chatbot developed as part of the CodSoft Artificial Intelligence Internship. The chatbot interacts with users by understanding text-based inputs and generating relevant responses.

##  Features
- Interactive conversation
- User-friendly interface
- Predefined responses for common queries
- Easy to customize and expand

##  Technologies Used
- Python
- VS Code

##  Learning Outcomes
- Basics of Natural Language Processing
- Python programming
- Chatbot development
- User interaction handling
